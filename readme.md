**Instrucciones de uso y ejecución de programa para gestión de catálogo y flujo de préstamos de libros de una biblioteca.**

*Cómo ejecutar:*
- Se inicializa o launchea medienate el la ejecución de main.py


*Archivos:*
- main.py: programa principal que despliega el menú para la gestión de la biblioteca
- utilidades.py: ejecuta las funciones que corresponden a cada estructura del programa main.py

*Requerimientos*
R1 - dict: Es una estructura HashMap que registra libros y busca en el catálogo con complejidad O(1)

R2 - sorted(): Es un TreeMap que muestra el catálogo ordenado por código con complejidad O(nlog n)

R3 set: Es una propiedad de HashTable que registra nuevos socios sin duplicados y verifica su existencia con O(1) promedio.

R4 set: Se usa como Operaciones de insercción, diferencia y unión por géneros
